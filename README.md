# ADULT TREND HUB — 収益化を目指す成人向けトレンドサイト

Xの成人向け関連投稿へのリンクランキングと、FANZA公式アフィリエイトAPIから取得した作品情報を同じサイトにまとめるNode.jsプロジェクトです。投稿動画そのものは転載せず、元投稿へリンクします。作品情報はAPI IDとアフィリエイトIDを設定した場合のみ表示します。

## 必要なもの
- Node.js 18以上
- X APIのBearer Token（X投稿ランキングを使う場合。利用プランと検索権限によって動作が異なります）
- FANZA/DMMアフィリエイトAPIのAPI IDとアフィリエイトID（作品情報を使う場合）

## ローカル起動
```bash
npm install
# macOS / Linux
X_BEARER_TOKEN="your_x_token" DMM_API_ID="your_api_id" DMM_AFFILIATE_ID="your_affiliate_id" npm start
# Windows PowerShellでは環境変数を個別に設定してから npm start
```
ブラウザで `http://localhost:3000` を開きます。APIキーはHTMLやGitHubへ書かず、環境変数として設定してください。

## 公開時の環境変数
- `X_BEARER_TOKEN` — X API Bearer Token
- `DMM_API_ID` — FANZA/DMM API ID
- `DMM_AFFILIATE_ID` — アフィリエイトID
- `PORT` — ホスティング環境が指定する場合に利用（通常は自動設定）
- `CACHE_SECONDS` — API結果のキャッシュ秒数（既定600秒）

ホスティングサービスの設定画面に環境変数として登録してください。秘密情報をチャットや公開リポジトリへ貼らないでください。

## 収益化までの手順
1. GitHubなどにコードをアップロード（APIキーを含めない）。
2. Node.js対応ホスティングに接続し、Build Command `npm install`、Start Command `npm start` を設定。
3. 上記の環境変数をホスティングの設定画面で登録。
4. FANZA/DMMアフィリエイトの規約・API仕様を確認し、アカウント登録とAPI利用申請を行う。
5. 成人向けコンテンツを明示的に許可する広告サービスがある場合のみ申請。一般向け広告ネットワークは成人向けサイトを禁止・制限していることがあります。
6. 運営者情報、問い合わせ先、プライバシーポリシー、利用規約を実際の運営内容に合わせて修正。
7. 検索結果を並べるだけでなく、編集部の独自レビュー・ジャンル解説・比較記事を追加。
8. 公開前に、各API・SNS・アフィリエイト・広告サービスの規約と日本の関連法令を確認。

## 重要な注意
- このZIPは公開・収益化に向けたコード一式です。まだインターネット上に公開されておらず、APIアカウントや広告審査も設定されていません。
- X APIの利用可否、料金、検索対象、センシティブな投稿へのアクセスは契約プランやXの規約・仕様に依存します。成人向け投稿がAPIから返る保証はありません。
- 作品情報APIの項目やパラメータは変更される場合があります。FANZA/DMMの公式APIドキュメントで最新仕様を確認してください。
- 年齢確認画面は自己申告式の簡易ゲートであり、本人確認や法的な年齢確認を行うものではありません。必要な場合は適切な年齢確認方法を導入してください。
- 違法アップロード、未成年者が関わる性的コンテンツ、本人の同意なく公開された性的画像・動画は掲載しないでください。著作権・肖像権・プライバシー侵害の申告窓口を運用してください。
- 広告やアフィリエイトは報酬発生を保証しません。広告であることを明示し、成人向けサイトを許可するサービスだけを使ってください。
